# GONE Privacy Policy

Last updated: September 2, 2026

GONE is a browser extension that replaces the New Tab page with a private, on-device summary of where the user's active browser time went.

## Data GONE handles

After the user grants optional tab access, GONE processes the active tab's URL, page title, tab identifier, window identifier, and timestamps. It reduces URLs to normalized domains, redacts likely sensitive text from tab titles, and records timestamped active-tab intervals. GONE also uses Chrome's locally cached favicons to identify websites in the interface.

This information is used only to provide GONE's browser-time reflection, including summaries for the last hour, last three hours, and today.

## Data GONE does not access

GONE does not read page contents, form inputs, messages, cookies, passwords, authentication data, keystrokes, mouse movements, scrolling activity, financial information, health information, or precise location. It does not request Chrome's browsing-history permission.

## Storage and retention

All extension data is processed and stored locally on the user's device using Chrome extension storage. Timestamped active-tab intervals are retained for up to eight days. Compact current and previous reflection state may remain until it is overwritten, the extension's storage is cleared, or the extension is removed.

## Sharing and transfers

GONE does not transmit browser activity to the developer, external servers, analytics services, advertising services, AI models, or other third parties. It does not sell user data. Favicons are loaded from Chrome's local favicon cache rather than a remote logo provider.

The optional “Buy me a coffee” link opens an external website only when the user chooses it. GONE does not attach browser-activity data to that link.

## User control

Tab and favicon access are requested only after the user chooses to continue. Users can revoke these optional permissions through Chrome's extension settings. Removing GONE from Chrome deletes its extension storage from the browser profile.

## Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

GONE uses browser data only to provide and improve its single user-facing purpose. It does not use or transfer user data for advertising, creditworthiness, lending, or any unrelated purpose, and it does not allow humans to read user browser data.

## Changes to this policy

If GONE's data practices change, this policy and the Chrome Web Store disclosures will be updated before the changed version is published.
